Waiting…
Press a button on every controller. Browsers hide a gamepad until it sends input, so a pad that is connected but untouched will not be listed here.

If a controller never appears: the browser is not getting it from the OS. On Windows a second Xbox controller over Bluetooth usually does not get an XInput slot, so no browser can see it even though Windows shows it as connected and its Xbox button still opens Game Bar. Connect it with a USB cable — wired pads always enumerate — or use an Xbox Wireless Adapter.

In the game, Enter on the title screen joins a second player on the keyboard instead, so co-op works without a second pad.
